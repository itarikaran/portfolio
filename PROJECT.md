# Ari Karan Portfolio

## Overview

A responsive personal portfolio for Ari Karan, a MERN Stack Developer and Computer Science and Engineering student based in Tirunelveli, Tamil Nadu, India. The site presents his background, skills, education, selected projects, coding profiles, and contact details.

## Features

- White-first editorial design with violet and blue accents.
- Responsive page layouts and a collapsible mobile navigation menu.
- About, skills, projects, education, coding profiles, and contact sections.
- TaskFlow and JobTrack project information with links to their repositories and demos.
- CSS product concept previews; these are illustrative previews, not screenshots of the live applications.
- Résumé download link and supplied portrait and monogram assets.
- Scroll-based section navigation state and reveal effects, with reduced-motion support.
- Semantic landmarks, skip link, page metadata, and Open Graph metadata.
- A small Node.js development server and a static build script. The site has no npm package dependencies.

## Technology

- HTML for page content (`index.html`).
- CSS for layout, responsive behavior, visual design, and motion (`src/styles.css`).
- Browser JavaScript for mobile navigation and scroll interactions (`src/main.js`).
- Node.js built-in modules for local serving and static file copying (`server.js`, `build.js`).
- npm scripts as command shortcuts; no package install is required.

## Requirements and setup

Install Node.js (18 or later recommended). Clone the repository, then change into its root directory. There are no dependencies to install.

```powershell
git clone <repository-url>
cd portfolio
```

## Development commands

```powershell
npm run dev
```

Starts the Node server at `http://127.0.0.1:4173`. Set the `PORT` environment variable to use another port. Stop the server with `Ctrl+C` before starting another process on the same port.

```powershell
npm run build
```

Creates or replaces `dist/` with the static site: `index.html`, `src/`, and the contents of `public/`.

```powershell
npm run preview
```

Runs the same server command as `npm run dev` from the project root. It does not switch the server to serve `dist/`.

## Deployment

Build the site with `npm run build`, then configure a static hosting provider to publish the contents of `dist/`. The build includes all required page files and public assets. Configure the host's site root or output directory as `dist`.

The current server is intended for local development; it binds to `127.0.0.1`. Do not use it as a public production server. The portfolio links to the supplied hosted project demos and external profiles.
